# 2026-09-27: Phase 3 (tools as pages + FFmpeg pack)

Back to [[README]] · Plan: [[Master Plan]] · Packs: [[Packs]] · Tools: [[Tools]]

## Summary

Phase 3 is **complete and shipped in the installer**. Five concurrent builders finished: one built the FFmpeg pack and packs framework; one restyled tool pages and cut the Workspace duplicates; one cleaned up utilities; one integrated tools into the file manager; one verified the image/document/focus tools. The **installer now ships** with Search.exe, the engine, tool pages (32 tools across 8 packs), Settings › Packs, the FFmpeg pack (optional, 71 MB), the player, media utility, and record/remux/transcode capabilities. All tests pass. Known issues are documented below.

## Known issues (not done, needs follow-up)

### Blockers (fix before next release)

**Screen Recorder visibility bug:** should be hidden but isn't. `appScreens.ts:834` (`tool.hidden = tool.id in offInSearch`) overwrites Builder A's `hidden: true` at line 415. Screen Recorder is now in the tools index, field, and shipped catalog.json (confirmed in build/Search/tools/catalog.json). The engine has no screenrec feature (shipped with --no-default-features), and its Tauri toolbar/picker windows don't work. Test `index.test.ts` misses this (only checks offInSearch-listed ids). **Fix:** add 'screen-recorder' to offInSearch.ts and add a regression test asserting it's not in the index.

**Reminders reconciliation bug:** Reminders is listed (Focus pack). Opening it calls `reconcile_reminder_tasks`, which runs `Get-ScheduledTask -TaskPath '\\KeepItLocal\\*'…`. The wildcard matches `\\KeepItLocal\\Cron\\*` (Cron panel in Dev Toolkit), so opening Reminders deletes every Cron task. Also deletes Workspace's real reminders on the same PC. **Fix:** match exact folder `'\\KeepItLocal\\'`, or move Search's tasks to `\\Search\\<world>\\Reminders\\`. For now, add 'reminders' to offInSearch until Cron panel is fixed.

### High-severity issues

**Shell-open from tool pages:** CleanerAnalyzer's "Open location" and DuplicatePreview's open button call `open_search_result_path`, which runs .exe/.msi/.bat and mounts .iso. Old large files are mostly installers. **Fix:** use `revealItemInDir` for folders, `host:open.file` (FileKinds) for files.

**ToolCalls.Refused incomplete:** tool pages can invoke engine commands from cut tools: apply_hardening_tweak, revert_hardening_tweak, revert_all_hardening (Windows Hardening hidden), plus reconcile_reminder_tasks (Reminders). A script bug in a tool rendering HTML (CSV/Markdown/Diff) can change Windows settings. **Fix:** extend ToolCalls.Refused to include these commands; add a Kit test.

**FOF_WANTNUKEWARNING prompt has no owner window:** File Manager delete shows Windows' "delete permanently?" prompt from the headless engine. It can open behind Search or off-focus. Engine call blocks. **Fix:** pass Search's HWND to the engine, or let the page check before sending delete.

### Medium-severity issues

**FFmpeg protocol whitelist:** ffprobe/ffmpeg demux from file content. A crafted 'film.mkv' that's really an HLS playlist reads local files via `file://` protocol. Output goes to cache and is served to the page. **Fix:** add `-protocol_whitelist file,pipe` before every `-i` (Remux.cs Player.cs, the ffprobe and sidecar calls). Force sidecar demuxer from extension. Add test case.

**Player precedence:** `OpenLocal` (File Manager) uses `FileKinds.ActionForPath` without `FileKinds.Opening`, so MKV from File Manager opens in its own app even with the pack installed (field does use Opening). **Fix:** call `Opening(ActionForPath(path), path, FfmpegBin)` in OpenLocal.

**Pack download UX:** Settings page redraws 4 times/sec during download (UI.Every(0.25) → Changed → Show). Keyboard focus and scroll lost. **Fix:** update only the progress-text detail on ticks; rebuild on state changes (Tell).

**FFmpeg user override:** once the pack is installed, `resolve()` silently switches from a user's chosen ffmpeg to the pack, and ffmpeg_status reports 'pack'. **Fix:** put override first (explicit choice wins), or clear override on pack install and say so.

### Lower-severity issues

**Pack remove crash leftovers:** Remove renames to `.removed-*` but Sweep only scans root-level ids, so interrupted removes leave 144 MB behind. **Fix:** scan and remove `.removed-*` at start of Install/Remove.

**Pack update with file in use:** after update, TryDelete is skipped if old folder is locked (remux running from it). Partial folder stays. **Fix:** call Player.Forget before the swap.

**Pack repair (same-version) untested:** most delicate code, no boundary test.

**Licence link timing:** FFmpeg licence link only shows after install (71 MB download). Can't read LGPL before starting. **Fix:** link to source commit's COPYING.LGPLv3 before install.

**FFmpeg tag mismatch:** NOTICE says pin `autobuild-YYYY-MM-last`, but actual tag is `autobuild-2026-08-31-13-27`. **Fix:** update NOTICE to match.

**`>ffmpeg` intent signal:** `packs.ffmpeg` has words ["install ffmpeg", "ffmpeg"] at Tier.Act, so bare `>ffmpeg` starts a 71 MB download. **Fix:** remove bare "ffmpeg", or make it just open Settings › Packs.

**Dead code in searchTools.ts:** helperPages names 'file-search-index' (screen removed), openTool refuses it. FileSearchIndex.svelte orphaned. Settings.svelte.bak committed as backup. **Fix:** remove helperPages entry, delete the files, trim stores/fileSearch.ts (used only by old Workspace shell).

**Layout redundancy:** +layout.svelte still pack-gates `initShredderListeners` (was only with privacy pack on; now page starts them). Left as-is; harmless.

**Installer cleanup:** uninstall keeps `%LOCALAPPDATA%\Search` (144 MB packs + 4 GB cache). Both can be rebuilt. **Fix:** remove `Cache\Play` and `Packs` on uninstall; profile data stays.

## Lessons

- Git Bash sed can silently normalize CRLF to LF on read. PowerShell `[System.IO.File]::ReadAllBytes` is reliable for checking actual bytes.
- JsonArray.Add(JsonObject) binds to generic Add<T> under AOT and only a full publish shows IL2026/IL3050 warnings; Debug is silent. Type as JsonNode.
- Chromium plays AC-3 MP4 audio silently. Probe stream types before trusting a playable container.
- Hidden/minimised tabs never load video; readyState stays 0. Test windows need ShowWindow/SetForegroundWindow for media checks.
- BtbN FFmpeg daily builds are deleted after ~2 weeks; pin month-end builds (kept long-term, with checksums.sha256).
- `location.hash` under SvelteKit hash router triggers location.reload(); use goto or links instead.
- SvelteKit refuses +server.ts routes when router.type is 'hash'; use a post-build script (vite ssrLoadModule).
- Tool pages already follow Search's theme live (WebView2 PreferredColorScheme handles it); no host call needed.
- Tauri shim labels tool tabs 'tool', so window-label gates in Workspace code (voice, push-to-talk, command mode) were running in every tab. Look for such gates when porting.
- Favicons cache per host, so tools.search tabs shared one icon. Keying by IconKey (tools.search-<id>) fixed it.
- Svelte 5 delegates onkeydown to root, so synthetic test events need `bubbles: true`.
- Bench `shot` times out if test window is minimised (-32000 frame). ShowWindow(SW_RESTORE) on your own process fixes it.
- `git diff --check` on CRLF files flags CR on changed lines as trailing whitespace; use `git -c core.whitespace=cr-at-eol diff --check`.
