# 2026-09-24

Back to [[README]]

## Done

- Ported Search from macOS to Windows (C# + WinUI 3 + WebView2) in
  `searchwin\`, feature for feature. See [[Changelog]].
- Size and performance: switched to Native AOT, from about 215 MB to 73 MB
  installed. See [[Decisions#D6 · Native AOT for release, with a ReadyToRun fallback]].
- Installer: NSIS, per-user, with the WebView2 bootstrapper. WinUI stays
  inside the app, because its runtime redistributable is 114.6 MB.
- The C++ frame is written up as the future plan. See [[Roadmap]].
- Fixed from user feedback, with screenshots:
  - doubled window buttons
  - the field's glow flickering
  - tabs too long (now 160 px)
  - no menu for settings, passwords and themes (now the hamburger `AppMenu`)
- Went through every feature on screen and fixed what was broken. See [[Testing#What has been verified]].
- **User bug:** the app closed when hovering *View* in the hamburger menu.
  Cause: the release build had no `Search.pri`. Fixed in `b7916e4`, and the
  installer was rebuilt. See [[Lessons Learned#The missing resource index]].
- Set up this vault as the project's second brain.
- Brainstormed built-in, privacy-respecting tools (converters, bangs, voice,
  clipboard manager, file/content search, FishCatcher, file manager, free AI)
  against the user's own KeepItLocal/Verifier/FishCatcher/AgentsBar projects
  and the third-party OmniRoute/my-clone repos, via a 10-subagent analysis
  workflow. No code changed. See [[Ideas/Built-in Tools]].
- Pushed to GitHub (`Topurrra/searchwin`). Removed the Claude co-author line from all commit messages; commits stay short from now on.
- Proposals written:
  - [[Ideas/Agentic Browser]]: Brave-grade shields plus a private, visible agent.
  - Page → Markdown for the agent (markdowner / html-to-markdown checked).
  - [[Ideas/KeepItLocal Workspace]]: 7-agent analysis. Workspace supersedes Guard/Memory as the source for the detector, clipboard, voice and firewall. Settled: one command registry, built first.

## Open

- The user reinstalls from `build\Search-Setup-1.0.0-x64.exe` and keeps testing.
- Passwords and real imports are for the user to try.
- Decided the [[Master Plan]] (D16–D19):
  - Workspace goes inside Search as a copied engine plus tool pages; Workspace itself is kept.
  - Tray mode is off by default.
  - No KeepItLocal Redact in Search.
  - FishCatcher instead of Edge SmartScreen; the Store for signing.
  - Windows OCR, with Tesseract as a pack.
  - Protection first.
- The detector question (C# port or DLL) is settled: `sensitive_scan.rs` simply runs inside the copied engine.
